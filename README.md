# 채림이네 이상한 음식 스토어
```chap06-spring-data-jpa``` 예제의 menudb를 사용하여 React기반으로 구현한 웹페이지입니다. 

이 페이지는 AI를 활용하여 바이브 코딩하였습니다. 
## Configuration

- ```36가지의 음식 메뉴가 DB에 등록```되어 있습니다.
- 각 메뉴는 ```12가지 카테고리```로 분류되어 저장되었습니다.
- 메뉴판의 우측 상단에 있는 검색 기능으로 메뉴명을 검색할 수 있으며, ```치즈돈까스```라는 메뉴를 예로 들어본다면 사용자의 입력값 전후로 페이지 내부에서 ```%``` 기호가 붙어서 ```돈까```라는 키워드만 입력해도 치즈돈까스가 검색결과로 출력될 수 있습니다.
- 각 메뉴상품은 주문가능(판매중), 준비중(판매불가)가 함께 표기되어 있으므로 현재 판매가능 상태를 사용자가 확인할 수 있습니다. 
- 구매 기능은 없습니다. ```상품 등록, 조회, 수정, 삭제```를 할 수 있도록 합니다. 즉, 소비자가 아닌 상품 판매자를 타깃으로 제작한 페이지입니다.

## How to Run

### 1. MySQL DB 연결
IntelliJ로 파일을 열고 DB를 연결한다.
DB의 연결 계정은 다음과 같다.
```
ID: ohgiraffers
Password: ohgiraffers
Database: menudb
```
연결을 완료하기 전에, 좌측 하단의 ```test connection``` 을 실행하여 에러를 방지한다.

### 2. spring boot 파일 실행
동봉된 spring boot(chap06-spring-data-jpa)파일의 application.yaml파일을 실행한다. 이때 프로세스가 종료되면 Error의 가능성이 있으므로, 지속적으로 실행중인지 확인한다. 

### 3. 프론트엔드 실행
#### 3-1. ```menu-app```을 Antigravity IDE로 연다. 
#### 3-2. ```C:\myWs\menu-vive-coding\menu-app\apps\05_vibe_design\complete ``` 라는 파일경로를 터미널로 연다.
#### 3-3. ```ls```를 입력하여 json파일의 여부를 확인한다.
#### 3-4. ```npm install```을 입력하여 파일을 실행시킬 준비를 한다.
#### 3-5. ```npm run dev```를 입력하여 파일을 실행한다.

#### 4. 해당 페이지로 접속한다.
브라우저에서 ```localhost:5173```을 입력한다. 그리고 ```Enter```키를 누르고,  완성본인 ```채림이네 이상한 음식 스토어``` 라는 보랏빛을 띄는 웹페이지가 보이면 성공이다.
